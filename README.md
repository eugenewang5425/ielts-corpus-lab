# IELTS Corpus Lab public mirror

Static public mirror of the IELTS Corpus Lab aggregate dataset and study interface.

- No Cambridge IELTS passages, audio, images, answer keys, or third-party full question banks are republished.
- The public dataset contains aggregate word statistics, topic indexes, source metadata, and provenance labels.
- The D1-backed primary deployment remains the database source of truth; this mirror exists for network compatibility.
