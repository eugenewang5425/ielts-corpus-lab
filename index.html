Transparent methodology

统计方法与版权边界

1. 统计单元

一篇阅读文章、一份听力转写、一条口语题目或一条写作题目作为一个文档。完全相同的本地 PDF 抽取文本按哈希去重。

2. 基础词与噪声

剔除 a、to、the 等功能词、数字词、题目指令、听力转写标记，以及 chart / graph / describe 等题型模板词。

3. 排名指标

Occurrence

语料内总出现次数。

Document frequency

至少出现一次的文档数。

Per 10k

每一万学习词中的出现次数。

Confidence

综合文档覆盖与独立来源数。

4. 口语主题合并

把每条来源记录拆成独立的 Part 1、Part 2、Part 3 问题，再通过受控主题词典归入规范主题。文本相同的问题合并为一题，但保留全部来源引用；相近主题通过人工别名表合并，例如 Music、Singing 和 Music event。

5. 来源题与学习内容

“来源题目”展示整理前的题目文本及其来源、时期、地区和链接，展开后提供适合该 Part 的回答框架。“本站练习与示范”是单独生成的练习层，包含思路、模板、示范回答和常用词，不冒充来源原题或官方答案。

6. 在线数据库与更新

公开数据以版本化 JSON 存放在 GitHub 仓库中。网页先读取最新版本清单，再加载统计库、合并口语库和练习问答库；更新 main 后，GitHub Pages 会向所有访客提供同一快照。

7. 版权与准确性边界

来源题目的所有权归标注的发布方或贡献者；本站只进行主题归类、文本去重和来源整理。剑桥文章、音频、图片及答案仍不公开复制。考生回忆与非官方汇编可能存在遗漏或措辞误差，应结合来源等级判断。
