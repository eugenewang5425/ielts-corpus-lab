Transparent methodology

统计方法与版权边界

1. 统计单元

一篇阅读文章、一份听力转写、一条口语题目或一条写作题目作为一个文档。完全相同的本地 PDF 抽取文本按哈希去重。

2. 基础词与噪声

剔除 a、to、the 等功能词、数字词、题目指令、听力转写标记，以及 chart / graph / describe 等题型模板词。

3. 排名指标

Occurrence

语料内总出现次数。

Document frequency

至少出现一次的文档数。

Per 10k

每一万学习词中的出现次数。

Confidence

综合文档覆盖与独立来源数。

4. 学习内容

每个口语主题包含按 Part 分类的原创练习问题。点击问题可查看中文回答思路、英文可替换模板、示范回答和常用词。它们用于训练组织答案的能力，不代表 IELTS 官方题目。

5. 在线数据库与更新

公开数据以版本化 JSON 存放在 GitHub 仓库中，网页每次打开都会先读取最新版本清单，再加载对应的统计库和练习问答库。更新 main 分支后，GitHub Pages 会把同一快照提供给所有访客。

6. 版权边界

公共网站发布聚合词频、主题索引、来源元数据和本站原创练习，不复制受版权保护的剑桥文章、音频、图片、答案或 Joe 等第三方完整题库。
