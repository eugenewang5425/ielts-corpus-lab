Transparent methodology

统计方法与版权边界

1. 统计单元

一篇阅读 Passage、一段听力 Part 原文、一条口语题目或一道写作题作为一个文档。剑桥雅思 4–21 按 Test / Passage / Part 切分；旧扫描中无法可靠恢复标题的部分改用完整页级统计单元，避免漏掉正文。完全相同的本地 PDF 与题目按内容哈希去重。

2. 基础词与噪声

剔除 a、to、the 等功能词、数字词、题目指令、听力转写标记，以及 chart / graph / describe 等题型模板词。

3. 排名指标

四科词表发布所有达到最低文档频次的词，不设置前 750 条或其他 Top-N 上限；总体与近五年均从对应范围内的全部已选统计单元重新计算。

Occurrence

语料内总出现次数。

Document frequency

至少出现一次的文档数。

Per 10k

每一万学习词中的出现次数。

Confidence

综合文档覆盖与独立来源数。

4. 阅读与听力词块

词块按大小写归一后的连续词序列精确计数，同时报告出现次数、文档覆盖和来源集合。高可信需覆盖约 12% 的统计单元并跨至少两个来源集合；覆盖不足或只见于单一材料层的词块降为中或探索。释义、搭配骨架和例句为本站原创学习内容，不复制原题长句。

5. 口语主题合并

把公开来源与本地 2026 题库拆成独立的 Part 1、Part 2、Part 3 问题，再通过受控主题词典归入规范主题。文本相同的问题合并为一题，但保留全部来源引用；1–8 月作为当前准备范围，9–12 月材料明确标为前瞻预测。

6. 练习优先与来源参考

主题展开后默认进入“准备的问题与示范”，包含思路、模板、示范回答和常用词；“来源参考”只在需要核对出处时打开，保留来源、时期、地区和链接，但不在主题卡上突出庞大的来源题目数量。

7. 在线数据库与更新

公开数据以版本化 JSON 存放在 GitHub 仓库中。网页先读取最新版本清单，再加载统计库、词块库、合并口语库和练习问答库；更新 main 后，GitHub Pages 会向所有访客提供同一快照。

8. 版权与准确性边界

来源题目的所有权归标注的发布方或贡献者；本站只进行主题归类、文本去重和来源整理。剑桥文章、音频、图片及答案仍不公开复制。考生回忆与非官方汇编可能存在遗漏或措辞误差，应结合来源等级判断。
